# 化学侦检数据平台业务逻辑说明书 V2.0

## 1. 核心原则

平台核心对象：

``` text
设备
```

不单独建立人员对象。

Telemetry：

``` text
设备现在是什么状态
```

Events：

``` text
设备发生了什么事件
```

Notify：

``` text
平台要求设备做什么
```

------------------------------------------------------------------------

# 2. 设备生命周期

收到Telemetry：

``` text
设备上线
```

连续2秒上报。

15秒没有Telemetry：

``` text
设备离线
```

重新收到Telemetry：

``` text
立即上线
```

------------------------------------------------------------------------

# 3. 设备分组

设备发现后：

``` text
未分组
```

平台可以操作：

``` text
加入小组
```

设备离线：

``` text
保留分组关系
```

容量：

``` text
39个编队
每编队10台设备
最低390台在线
```

------------------------------------------------------------------------

# 4. 报警业务

平台统一展示：

``` text
设备报警
```

不向客户展示内部检测模块名称。

报警流程：

``` text
Events type=0
↓
报警开始/持续
↓
Events type=1
↓
报警结束
```

------------------------------------------------------------------------

# 5. 物质报警

type=0：

``` json
{
"names":["DMMP"],
"conc":3.8
}
```

平台显示：

-   报警物
-   当前浓度
-   最高浓度

报警期间：

``` text
当前浓度 = 最新Event.conc
最高浓度 = Event.conc最大值
```

结束：

设备提供：

``` text
duration
peak_conc
```

作为最终结果。

------------------------------------------------------------------------

# 6. 跌倒报警

跌倒属于同一次报警过程。

不会建立第二条报警。

显示：

``` text
设备报警
跌倒状态
```

------------------------------------------------------------------------

# 7. 报警结束

正常：

设备发送：

``` text
Events type=1
```

平台记录：

``` text
duration
peak_conc
```

设备断联：

``` text
15秒无Telemetry
↓
结束报警
```

结束原因：

``` text
normal
offline
```

------------------------------------------------------------------------

# 8. 模式业务

设备模式：

  mode       含义
  ---------- ----------
  monitor    正常监测
  training   演练模式

切换：

``` text
平台Notify
↓
设备执行
↓
ACK
↓
Telemetry.mode更新
```

------------------------------------------------------------------------

# 9. Notify业务

## 文本通知

type=0

发送提示信息。

## 参数配置

type=1

用于未来远程配置。

当前不定义具体参数。

## 位置共享

type=2

根据设备分组，设备上线平台将定时下发位置共享信息：

例如：

``` text
A B 同组
C 不同组
```

发送：

A收到B

B收到A

C不接收。

------------------------------------------------------------------------

## 模式切换

type=3

``` text
training
monitor
```

------------------------------------------------------------------------

# 10. 指令执行结果

需要确认执行的Notify：

必须携带：

``` text
id
```

格式：

``` text
UUID v7
```

设备返回：

Events type=2。

结果：

``` text
success
failed
```

10秒无返回：

``` text
timeout
```

------------------------------------------------------------------------

# 11. 实时与历史数据

Telemetry高频数据：

不全部永久保存。

规则：

``` text
实时处理
+
周期采样
+
关键事件保存
```

重点保存：

-   报警
-   设备状态变化
-   指令记录
-   训练记录
-   轨迹

------------------------------------------------------------------------
